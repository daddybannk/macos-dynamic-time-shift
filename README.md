# macOS Dynamic Time Shift

Dynamic background changes with time criteria

<img src="preview.jpg" width="300px" alt="Preview">

## Setting Properties

- macOS version
- Day shift (hour)
- Day shift (minute)
- Night shift (hour)
- Night shift (minute)
- Position Y (up-down)

## Available macOS Versions

- 26 Tahoe
- 15.2 Sequoia
- 14 Sonoma
- 13.0 Ventura
- 12.0 Monterey
- 11.0 Big Sur (Color)
- 11.0 Big Sur
- 10.15 Catalina
- 10.14 Mojave
- 10.13 High Sierra (Day Shift Only)
- 10.12 Sierra (Day Shift Only)

## Default Values

- macOS version: 26
- Day shift (hour): 6
- Day shift (minute): 0
- Night shift (hour): 18
- Night shift (minute): 0
- Position Y (up-down): 50
